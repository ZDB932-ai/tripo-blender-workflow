# 按需操作说明

费用：任务范围内默认自主使用现有 Studio 积分，按项目 docs/workflow/credit-policy.md 执行，不逐次请批。参考/质量审阅、本地返工限制、未知任务对账仍保留。

网页操作先读取项目 docs/workflow/playwright-operations.md，按观察→唯一定位→确认行为/费用→执行一次→核验→留证，不将重复点击作为恢复方式。

共享状态、命令与 schema 只以项目 `tools/workflow/PRODUCTION.md` 为准。本文提供领域操作细节，不覆盖当前执行器。版本、报价与控件按实际运行核实。

- 输入模型身份、brief、参考包和run状态。studio_result_ready进入qa_review，表示检查进行中，恢复仍由本阶段继续；accepted模型只读审查不用倒改旧状态。保存visual-review.json，区分观察、推断与用户意见。
- 排查导入绑定错配时可对同版本网页预设动作采样，记录动作身份、版本与多个时刻；预览/选中/加入动画/收费生成不是同一操作，先读实际控件。网页证据仅用于定位，不自动证明可交付。必要时再比较另一格式或原始导入，不反复重新绑定。
- 预设点击可能立即触发重定向任务；首次使用先记录操作意图及授权依据，点击一次后等任务完成，记录实际余额变化（没有变化不等于永久免费）。不得把预设应用称为纯只读查看，也不把诊断预设当最终交付动作。
- 正侧背检查轮廓、厚度、缺失/多余肢体、腋下和腿间间隙、手脚、薄片、漂浮碎片、面数、UV/贴图接缝与PBR观感。DOM读数与截图结合；截图不足以证明流形或骨骼可变形。
- 画布操作先从当前DOM获得canvas边界，仅做相机旋转并截图确认朝向。不得沿用旧坐标或把相机旋转写成模型编辑。已实测3D页面截图可能超过5秒，适当用30秒超时，不因截图超时重生模型。
- 分类缺陷：参考或设计问题回reference；几何问题评估重拓扑/补全/分件；纹理问题评估局部修改/重纹理/PBR；动画目标评估绑定。已有图或几何足够时跳过不必要操作。
- 按需读取 operations.md。高级面板尚未端到端实测，先观察控件与能力，形成可回滚的新版本计划。精细Brush先证明选择、视角锁定和撤销可靠，否则用户完成必要手动步骤。
- base_model检查后读取项目 docs/workflow/studio-capabilities.md 与 studio-recipes.md 对应路由，同时评估Tripo Mesh Edit/分件补全/拓扑/纹理与Blender处理，不预设精修或绑定全部转Blender。输出缺陷证据、保护区、两方能力/费用或耗时估计、选择理由、退出条件；合格部分保留。需要内部诊断可导入副本，仍标base_model待验证。
- 检查完成时按 tools/workflow/RECOVERY.md 保存绑定当前 run/plan、实际来源和证据的报告，标 ready_for_transfer；若仅为内部诊断则标 diagnostic_transfer，base_model 仍待验证。
- Studio后处理在授权范围内每项独立run，固定源模型，交preflight与generate执行；回读比较修改区域和保护区域后再更新当前版本。需要精确修整交deliver与tripo-blender-polish。绑定默认先核查并使用适用的Tripo能力，再由tripo-blender-rig-motion检查和修权重，不无理由重绑。改拓扑/UV使受影响的贴图、权重、形态键与动作检查失效；遵守本地返工上限；Studio积分按持续授权使用。
- 动画往返按 docs/workflow/roundtrip.md：先完成必要结构修正，再决定是否上传稳定交换副本、原生绑定和生成目标动作。早期试绑用于定位未知结构风险；已有缺陷先修，合格骨架/clip复用。导回先核对实际属性、通道和完整播放，最终权重/材质/动作精修放在最后一次必要往返之后；硬质附件只在实际变形时修刚性随动。
