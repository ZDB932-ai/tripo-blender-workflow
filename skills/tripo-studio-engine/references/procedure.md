# 按需操作说明

共享状态、命令与 schema 只以项目 `tools/workflow/PRODUCTION.md` 为准。本文提供领域操作细节，不覆盖当前执行器。版本、报价与控件按实际运行核实。

- 按 tools/workflow/PRODUCTION.md，输入应是当前最终导出及技术验收证据，final用户最终验收可在本阶段完成后统一进行，不强迫自主模式提前再验收一次。先确认引擎、版本、现有项目目录、平台和用途；缺失时准备检查计划再询问，不擅自建新游戏。不因集成目标自动再生成Tripo模型。
- 核对交付哈希和验收范围，复制到项目版本化资产目录并保留来源。检查该引擎当前支持格式/导入器；对版本敏感行为用官方文档核验。需要转换时评估现有工具和损失，不静默增加付费服务。
- Unity项目操作先读取可用unity-cli技能；UPM变化使用unity-package-management。其他引擎按现有仓库规范和工具执行。未安装工具时报告具体缺口，不伪造导入结果。
- 验证单位和朝向、pivot、材质纹理路径、base color与法线颜色空间、roughness/metallic通道、透明、阴影。按目标测面数/材质数、纹理内存、LOD和碰撞；不把统一5万面当作所有平台标准。
- 角色动画需实际检查骨架映射、bind pose、权重、脚滑、关节扭曲、root motion和所需片段；无骨架时标not_performed并交refine提出独立计划，不声称可动画。
- 在用户允许的测试场景查看实际运行，记录截图/日志/测量环境。写engine-review.json包含source_sha256、项目和引擎版本、导入路径、通过项、失败项及未测项。交付可运行证据后再请求需要的用户验收，不修改原静态accepted范围。
