# Tripo Studio 功能选路表

核验日期：2026-09-27。本表是本项目制作决策索引，操作细节按需读 [Studio 配方](studio-recipes.md)，官方来源及当前界面差异见 [研究记录](../research/tripo-studio-2026-09-27.md)。执行状态、预算、提交和回执仍以协议 3.6 为准。

覆盖范围：官方教程的七类工作区、当前工作台的十二个制作入口及其已发现子功能、导出/资产管理和官网配套工具。功能会随模型、输入、套餐和版本变化；这不是所有账号隐藏功能的完整清单。`D` 表示官方资料有说明；`U` 表示本次实际页面观察到入口/设置；`E/V` 必须另有本项目执行/质量验证证据。本次研究没有产生新的 E/V。按钮可见不表示对所选源可执行。

## 先区分执行状态

- **当前单任务路线**：已有输入的生成与后处理按当前UI、预算和单候选协议操作；D/U不代表执行或质量通过。
- **需要目标模型核实**：Mesh Edit、分件子控件、视频限制、旧Stylization等，实际用到再查。
- **执行器待适配**：批量、一次多变体、参考批准前的Studio付费生图，不纳入日常必走流程。

这里只查本次所需条目，不逐件填写54项功能清单。

| G09 模型/质量/增强/隐私设置 | 输入槽、模型、面数或模式改变时重新核对全部参数 | preflight；保存实际参数、当前总报价及候选数量 | U；“仅分享”不等同完全私密，显示报价不是授权 |

## 几何、部件、拓扑和 UV

| ID / 功能 | 何时使用、怎样提高效率 | 接入位置 / 验收重点 | 本次证据 |
|---|---|---|---|
| M01 Mesh Edit | 轮廓大体正确，少数局部几何需要重新生成 | refine；先备份分支、框定缺陷和保护区；比较边界与全模 | D；生成页仍有“实时网格编辑即将上线”，需目标P2查看器核实 |
| M02 Segmentation v2 | 现有一体模型确需独立对象；按目标粒度选简单/均衡/详细 | refine；检查部件完整性、装配和分界，不以颜色数验收 | D/U；当前面板明确排除四边面和已绑定模型 |
| M03 Brush / Add Part / Merge | 自动拆分边界不合理；修边界而非整模重生 | refine；选区/遮挡可确认后提交，合并后核对残片与命名 | D；需要已分割输入才能核查细节控件 |
| M04 Fill Parts：Quick Cap | 切口只需封闭，不需要推断被遮挡结构 | refine；检查闭合、法线、切口形状；不能拿平盖冒充重建 | D/U入口；当前账户费用及源支持另核 |
| M05 Fill Parts：AI Completion | 拆出部件缺少内部/背面，需要体积重建 | refine；检查新体积、接合、穿插、厚度，未知结构须标注 | D/U入口；与快速封口分开评估 |
| M06 Retopology：三角 / 四边 | 面数、边流或可编辑性不符才重拓扑 | refine；轮廓、细部、关节和实际面数对比 | D/U；已有H源显示P1.0，不等同P2生成 |
| M07 局部部件重拓扑 / Smart Low Poly | 只优化高负担部件；简单形体先试合理预算 | refine；先确认部件多选是否可用；保护其余部分 | D；低模不必再全局减面，细节不靠面数标签保证 |
| M08 Smart UV | UV缺失、拉伸/接缝或布局效率不符合贴图需求 | refine；拓扑稳定后、最终贴图前；二维UV/三维联动检查 | D/U；当前上限80k三角或40k四边 |
| M09 UV布局比较 / Retry | 首次UV结果存在具体缺陷时比较备选 | refine；比较接缝、拉伸、密度、间距和利用率，不只追求百分比 | D；重试也是操作，核对试用/报价与剩余次数 |
| M10 部件属性与变换 | 模块化装配、隐藏检查、命名和定位 | refine；保持装配坐标与源身份，变换后重新检查接口 | D；删除/恢复为变更，查看/隐藏不能当成真实删除 |

## 纹理、材质与风格

| ID / 功能 | 何时使用、怎样提高效率 | 接入位置 / 验收重点 | 本次证据 |
|---|---|---|---|
| T01 Texture Gen：图片 / 文字 | 无纹理或整体风格不符；固定几何后生成底图 | refine→preflight；文字按材料区域描述；风格参考与形状参考区分 | D/U；本次可见2K/4K/8K及去光处理 |
| T02 Style Reference / 风格迁移 | 统一系列材质与色彩，几何已经正确 | refine；保留设计图案/身份，避免为换色重生几何 | D；具体参考入口按源模型实查 |
| T03 Remove Lighting / 去光处理 | 需要引擎重新打光时优先评估开启；手绘外观按风格决定 | preflight；中性光下检查烘焙阴影，非全局强制开关 | D/U；只影响新结果，不修复所有已生成材质 |
| T04 Magic Brush / 局部重绘：生成模式 | 大部分纹理合格，只修局部图案或颜色 | refine；视角锁定、预览、刷选应用、保存分别核查 | D/U；当前“生成纹理预览”显示5积分，不能当免费预览 |
| T05 Magic Brush：绘制模式 | 精确局部补色或小瑕疵 | refine；核对遮挡/边界、撤销、保存；不假定同步更新所有PBR通道 | D/U；无法可靠选区则保留现场转可控工具 |
| T06 Texture Upscale / 4K、8K | 几何/UV/底图内容已合格，但最终观看距离下分辨率不足 | refine；内容修复之后再放大，按最终像素密度选择 | D/U；8K指BaseColor，Normal/ORM可能为4K |
| T07 PBR Generator | 缺少所需物理材质通道或颜色修改导致通道不一致 | refine；在最终外观后核对/生成，不重复已有合格通道 | D/U；金属、粗糙度、法线与ORM通道要按实际文件验证 |
| T08 PBR显示 / Metallic、Roughness属性 | 检查材质表现、快速调参 | refine；显示开关不代表材质已导出；区分常量与贴图 | D；以导出文件和目标引擎为准 |
| T09 Stylization：Voxel / LEGO / Figurine等 | 用户要求新的形体风格时，作为早期分支探索 | reference/refine；改变几何则重做下游检查，不在最终阶段随意应用 | D旧教程；本次导航未见独立入口，当前可用性unknown |

## 每次如何使用本表

总控只在需要选择处理时查相关ID，记录“采用 / 已满足跳过 / 不适用 / 当前输入不兼容 / unknown待核实”及一句依据。只读检查和同版下载不要求逐项填表。制作时在现有 `generation-route-vNNN.md` 内增加相关ID、源版本、前置条件、UI证据、预期变化、保护项、会失效的下游结果和退出条件；不为每个未使用功能新建批准。

完整流程参考：模块化看 G06/M02–M07，UV看 M08–M09，材质看 T01–T08，动作看 A01–A07。失败先回最早出现缺陷的阶段；不要用贴图遮几何错误、用分件代替正确蒙皮、用升分辨率修接缝，或用重生几何修下载问题。
